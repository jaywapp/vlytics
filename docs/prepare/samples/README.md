# UI 시안과 검증

2026-09-20 · UC-008 B에 따라 **sample2 경기 브리핑**을 채택했다.

## 실행

[시안 목록](index.html)이나 각 `index.html`을 브라우저에서 직접 연다. 빌드·패키지 설치·서버·환경 변수가 필요 없다. `shared.css`와 `shared.js`를 포함한 이 디렉터리 구조를 유지한다.

| 시안 | 정보 구조 | 주요 조작 | 선택 상태 |
|---|---|---|---|
| [sample1](sample1/index.html) | 일정 표 + 선택 경기 검사 패널 | 남녀 필터, 경기 상세, 운영 상태 | 비교 이력 |
| [sample2](sample2/index.html) | 경기 선택 + 브리핑 + 모델 비교 | 통계/GPT/Claude/Gemini 선택, 근거·Market 펼침 | 주 방향 채택 |
| [sample3](sample3/index.html) | 코호트 설정 + 짝비교 + 성능 표 | 리그 변경, 공통 표본·Brier 차이 재계산 | 비교 이력 |

상단 `상태` 선택에서 정상·빈 화면·로딩·오류를 전환한다. 오류의 다시 시도는 합성 정상 화면으로 돌아온다. 실제 네트워크 복구를 수행하지 않는다.

## 데이터와 구현 경계

- 팀명·일정·확률·결과·실행 상태는 합성이다. 실제 KOVO 데이터, Provider 응답, API 키를 포함하지 않는다.
- sample2는 같은 경기에서 서로 다른 모델의 독립 확률을 비교한다. 남자부 Gemini 시간 초과는 `계산 불가`로 표시하고 선택에서 제외한다.
- sample3의 Brier/Log Loss/적중률/짝비교 표준오차는 합성 관측 배열에서 계산한다. 시장 기준선은 `미수신`, 작은 표본의 해석은 `표본 부족`으로 표시한다.
- 단일 HTML 시안은 제품 기능을 구현한 것이 아니다. 정식 제품에는 별도 History의 전체 필터, 서버 집계·인증·수집·불변 저장·공동 점수 모델을 구현해야 한다.
- 모바일의 경기 선택과 넓은 표는 영역 안에서 가로 스크롤한다. 문서 전체는 가로로 넘치지 않는다.
- 별도 이미지 생성 자산을 쓰지 않는 데이터 UI다. 표·확률 그래프·상태는 의미 있는 HTML/CSS로 만든다. 제품 구현 시 선택된 시각 규칙은 [DESIGN.md](DESIGN.md)를 따른다.
